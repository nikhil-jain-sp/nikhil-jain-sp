## 🛠️ Selected Projects

### 🎬 [Video Resume Screener](https://github.com/nikhil-jain-sp/video-resume-screener) *(in progress)*
A multi-agent LangGraph workflow that screens video resumes for a sports and media agency. It gives recruiters evidence and a suggested tier, and a person always makes the final call. Key design choices:
- Guardrails live in code, not prompts: transcript redaction, prompt-injection stripping, and quote-verified scoring (a score without a verbatim quote is dropped)
- No rejection by a model, and no face, emotion, accent or voice-tone scoring
- Counterfactual fairness eval (name-swap check) and a test suite
- Runs offline for demos, or against any OpenAI-compatible endpoint (hosted, vLLM, Ollama)

**Stack:** Python, LangGraph, OpenAI-compatible LLMs, pytest


### 🔍 [Vulnerability Scanner](https://github.com/kushalbajje/vulnerability-scanner)
A team-built tool that discovers devices on a local network, uses Nmap to find security weaknesses, and generates simple, readable risk reports, designed so non-experts can use it.

**Stack:** Python, Nmap
